# Portfolio de Informática I

Esta carpeta se distribuye mediante `informatica-1bach.zip`. Al descomprimirlo debe aparecer una única carpeta llamada `informatica-1bach`.

Trabajo habitual en LliureX:

1. Coloca `informatica-1bach` en `~/Documentos/Informatica-I/`.
2. Abre la carpeta completa en VS Code.
3. Trabaja, prueba, guarda, revisa y crea commits locales con Git.

Git funciona sin conexión y sin una cuenta iniciada. GitHub es un remoto ocasional: solo se conecta cuando el profesor lo indique individualmente. No clones esta plantilla y no incluyas `.git/`, contraseñas, tokens, `.venv/` ni datos personales.

`README.md` presenta el repositorio. `docs/index.md` es la portada del portfolio. La carpeta `.github/` contiene el workflow que se usará para GitHub Pages después de la primera sincronización autorizada.
